# Finance Frontend

A React-based frontend for the Finance application.  
This project connects to a FastAPI backend hosted on Render.

---

## 🚀 Features
- React frontend with Axios for API calls
- Connects to FastAPI backend (`https://finance-backend-1-lvt3.onrender.com`)
- Deployed on GitHub Pages
- Supports local development and production builds

---

## 📦 Installation

Clone the repository and install dependencies:

```bash
git clone https://github.com/vaishnavithunuguntla/finance_frontend.git
cd finance_frontend
npm install
